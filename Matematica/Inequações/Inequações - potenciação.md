#math #inequacoes 

Sejam as inequações, sendo f(x) uma função real de variável real.
$$[f(x)]^n > 0 , [f(x)]^n < 0, [f(x)]^n \geq 0, [f(x)]^n \leq 0, \text{ em que } n \in \mathbb{N}^*$$

1º) Toda potência de base real e expoente ímpar conserva o sinal da base, isto é
$$\begin{align*}
& a^{2n + 1} > 0 \iff a > 0 \\
& a^{2n + 1} = 0 \iff a = 0 \\
& a^{2n + 1} < 0 \iff a < 0
\end{align*}$$
2º) Toda potência de base real e expoente par é um número não negativos, isto é:
$$a^{2n} \geq 0, \forall a \in \mathbb{R}, \forall n \in \mathbb{N}$$

Assim, sendo as seguintes equivalências

$$\begin{align*}
& [f(x)]^n > 0 \implies
\begin{cases} 
 f(x) > 0 \text{ se } n \text{ é ímpar}  \\
 f(x) \neq 0 \text{ se } n \text{ é par }
\end{cases}
\\
\\
& [f(x)]^n < 0 \implies
\begin{cases} 
 f(x) < 0 \text{ se } n \text{ é ímpar}  \\
 \exists x \in \mathbb{R} \text{ se } n \text{ é par }
\end{cases}
\\
\\
& [f(x)]^n \geq 0 \implies
\begin{cases} 
 f(x) \geq 0 \text{ se } n \text{ é ímpar}  \\
 \forall x \in D_{f} \text{ se } n \text{ é par } 
\end{cases}
\\
\\
& [f(x)]^n \leq 0 \implies
\begin{cases} 
 f(x) \leq 0 \text{ se } n \text{ é ímpar}  \\
 f(x)=0 \text{ se } n \text{ é par }
\end{cases}
\end{align*}$$
