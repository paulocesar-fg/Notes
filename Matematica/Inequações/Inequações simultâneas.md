## Definição
A dupla desigualdade $f(x) < g(x) < h(x)$ pode ser decomposta:
$$f(x)< g(x) < h(x) \iff 
\begin{cases}  
 f(x) < g(x) \text{ (1) }  \\
 g(x) < h(x) \text{ (2) }
\end{cases}$$
Seja $S_{1}$ solução de (1) e $S_{2}$ solução de (2), o conjunto desigualdade dupla é $$S = S_{1} \cap S_{2}$$
### Exemplo
Seja a inequação $3x+2< -x +3\leq x+4$, resolva-a em $\mathbb{R}$
$$3x+2 < -x + 3 \leq x+4 \iff 
\begin{cases} 
 3x+3<-x+3 \text{ (1)}  \\
 -x+3 \leq x+4 \text{ (2) }
\end{cases}$$
Para (1)
$$3x+2 < -x+3 \iff 4x<1 \iff x < \frac{1}{4}$$
Logo, 
$$S_{1} = \left\{   x \in \mathbb{R} \middle| x < \frac{1}{4} \right\}$$
Para (2)
$$-x+3\leq x+4 \iff -2x \leq 1 \iff x \geq -\frac{1}{2}$$
$$S_{2} = \left\{   x \in \mathbb{R} \middle| x \geq -\frac{1}{2}  \right\}$$
Assim,
$$S=S_{1}\cap S_{2} = \left\{  x \in \mathbb{R} \middle| -\frac{1}{2} \leq x < \frac{1}{4} \right\}$$
