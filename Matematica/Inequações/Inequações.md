#math #inequacoes

## Definição
Sejam as funções f(x) e g(x) cujos domínios são respectivamente $D_{1} \subset \mathbb{R} \text{ e } D_{2} \subset \mathbb{R}$. Chama-se **inequações** na incógnita x a qualquer uma das sentenças abaixo.

$$
f(x) > g(x), f(x) < g(x), f(x) \geq g(x), f(x) \leq g(x) 
$$
EX: $\sqrt{ x-2 } \leq \frac{1}{x-3}$ é inequação onde $f(x) = \sqrt{ x-2 } \text{ e } g(x) = \frac{1}{x-3}$.

### Domínio de validade
$D = D_{1} \cap D_{2}$, em que  $D_{1}$ é domínio de $f$ e $D_{2}$ é domínio de g. É evidente que, para todo $x_{0} \in D$, estão  definidos $f(x_{0}) \text{ e } g(x_{0})$ isto é:
$$x_{0} \in D \iff (x_{0} \in D \land x_{0} \in D_{2}) \iff (f(x_{0}) \in \mathbb{R} \land g(x_{0}) \in \mathbb{R})$$

### Solução e conjunto solução
$x_{0}$ é solução para $f(x) > g(x)$ se $f(x_{0}) > g(x_{0})$ é verdadeiro para $x_{0}$. O conjunto solução é o conjunto de todos os $x_{0}$ que satisfazem a sentença $f(x) >g(x)$.

$$x_{0} \in S \implies x_{0} \in D \text{, isto é, } S \subset D$$
