## Definição

A [[Funções | função]] afim(também chamada de função do 1º grau) é definida pela forma geral
$$f(x) = ax +b$$
onde:
a = coefiente angular($a \neq 0$)
b = termo independente

#### Crescente ou descrente
Se a > 0 f é crescente, se a < 0 f é decrescente. 

#### Coeficiente angular
O coeficiente angular, tambrém chamado de taxa de variação da função, geometricamente, é a tangente do ângulo $\theta$ do triângulo retângulo de catetos  $\Delta x=x_{i+1} - x_{i}$ e $\Delta y=f(x_{i+1}) - f(x_{i})$. 
$$a = \tan{\theta} = \frac{\Delta y}{\Delta x} = \frac{f(x_{i+1}) - f(x_{i})}{x_{i+1} - x_{i}}$$
#### Termo independente 
O termo independente é o ponto no qual o eixo y é cortado (isto é, $f(0)$).

#### Zero da funçao
$$ax + b = 0 \iff x = -\frac{b}{a}$$
