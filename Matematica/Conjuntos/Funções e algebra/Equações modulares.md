## Definição
Lembremos a propriedade do módulo dos números reais para k > 0
$$|x| = k  \iff x = k \text{ ou } x =-k$$
1) Resolver $|2x - 1|=3$
Então
$$|2x-1| = 3 \implies \begin{cases}
2x - 1 = 3 \implies x  = 2 \\
\text{ou } \\
2x -1 = -3  \implies x = -1
\end{cases}$$
Assim, $S = \{2, -1\}$

2) Resolver $|3x - 1| = |2x + 3|$ 
Pela propriedade [[Módulo| modular]] $|a| = |b| \iff a =b \text{ ou } a = -b$
Temos
$$|3x-1| = |2x+3| \iff \begin{cases} 
3x - 1 = 2x +3 \implies x = 4 \\
3x - 1 = -2x - 3  \implies x = -\frac{2}{5}
\end{cases}$$
Assim,  $S = \{4 , -\frac{2}{5}\}$

3) Resolver $|x+1| = 3x + 2$
$3x + 2 \geq 0 \implies x \geq -\frac{2}{3}$ , para que seja possível a igualdade. Dessa forma, supondo $x \geq -\frac{2}{3}$ temos
$$|x+1| = 3x + 2 \implies \begin{cases} 
x = -\frac{1}{2} \\
x + 1 = -2x - 2 \implies - \frac{3}{4} \text{(não convém)}
\end{cases}$$
Logo, $S = \left\{  - \frac{1}{2}  \right\}$.
