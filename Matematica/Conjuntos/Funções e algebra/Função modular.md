#math #funcoes 

Uma [[Funções | função]] de R em Rrecebe o nome  de função módulo ou modular quando cada $x \in \mathbb{R}$associa o elemento |x| em R.
$$f(x) = |x| \text{, isto é, } f(x) = \begin{cases}
 x \text{ se x >= 0} \\
 -x \text{ se x < 0}
\end{cases}$$
O gráfico da função módular é a reunião de duas semiretas de origem O, que são as bissetrizes do 1º e 2º quadrante. $\mathrm{Im} = R_{+}$ 

![[grafico-funcao-modular.png]]


### Exemplos 
Defina a imagem da função $f:\mathbb{R^{*}\to R},f(x)= \frac{|x|}{x}$ 
$$|x| = \begin{cases}
 x,\text{ se } x >0  \\
 -x, \text{ se } x <0
\end{cases}$$
Assim para $x>0,f(x) = \frac{x}{x} =1 \land x<0, f(x) = \frac{-x}{x} = -1$
