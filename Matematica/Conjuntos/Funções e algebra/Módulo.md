## Definição

Sendo $x \in \mathbb{R}$, define-se módulo ou valor absoluto de x, que se indica por $|x|$ , por meio da relação 

$$\begin{cases}  
|x| = x \text{ se } x \geq 0  \\
\text{ ou} \\
|x| = -x \text{ se } x \leq 0 
\end{cases}$$
### Propriedades
1) $|x|\geq 0, \forall x \in \mathbb{R}$
2) $|x|=0 \iff x = 0$
3) $|x||y| = |xy|$
4) $|x|² = x²$
5) $x \leq |x|, \forall x \in \mathbb{R}$
6) $|x+y| \leq |x| + |y|, \forall x, y \in \mathbb{R}$
7)  $|x-y| \geq |x| - |y|, \forall x, y \in \mathbb{R}$
8) $|x|\leq a \land a > 0 \iff -a \leq x \leq a$
9) $|x| \geq a \land a > 0 \iff x \leq -a \lor x >a$
