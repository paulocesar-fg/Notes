#math #logic #fme 

Servem para indicar a quantidade de elementos de um conjunto sobre o qual uma proposição se aplica. 

Observação: Dessa forma, é possível transformar uma sentença aberta em uma proposição, e  atribuir-lhe um valor lógico.

### Conectivo universal $\forall$

O símbolo $\forall$ (em latex `\forall` ) Lê-se: "para todo" ou "qualquer que seja". Ele serve para afirmar que determinada afirmação é válida para todos os elementos de determinado conjunto.

### Conectivo existencial $\exists$

O símbolo $\exists$ (em latex `\exists`) Lê-se: "existe", "existe um" ou "existe pelo menos um". Ou seja, caso exista pelo um elemento que valide a proposição, então ela será considerada verdadeira.
