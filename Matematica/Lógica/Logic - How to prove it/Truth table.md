## Definition

A **truth table** is  a mathematical table used in logic to **show the truth value of a compound statement for all possible truth values of its components.**

**Key points about truth tables:**

1. **Columns:** Each column represents a statement (proposition) or a combination of statements.
    
2. **Rows:** Each row represents a possible combination of truth values (true or false) for the statements.
    
3. **Truth values:** Usually represented as **T** (true) or **F** (false), or 1 (true) and 0 (false).


#### Example

Truth table for $P \iff Q$ (P if and only if Q):

| P   | Q   | $P \iff Q$ |
| --- | --- | ---------- |
| V   | V   | V          |
| V   | F   | F          |
| F   | V   | F          |
| F   | F   | V          |
