## Definition

In mathematics logic, a connective( also called a logical connective) is a symbol or word used to **combine two or more statements(propositions) into a new statements**. 

The most common conneives are:

<hr>

#### And(^) - Conjunction

True only if both statements(propositions) are true. 

Let P and Q a propositions, then: 
$$A \land B$$ Read: "A and B"

##### Truth table

| P   | Q   | $P \land Q$ |
| --- | --- | ----------- |
| V   | V   | V           |
| V   | F   | F           |
| F   | V   | F           |
| F   | F   | F           |
|     |     |             |

<hr> 

#### Or(v) - Disjunction

True if at least one statement is true.

Let P and Q a propositions, then: 

$$A \lor B$$
Read: "A or B"

##### Truth table

| P   | Q   | $P \lor Q$ |
| --- | --- | ---------- |
| V   | V   | V          |
| V   | F   | V          |
| F   | V   | V          |
| F   | F   | F          |
|     |     |            |

<hr> 


#### Not (¬) - Negation

Reverses the truth value of a statement.

Let P a proposition, then:
$$\neg P$$
Read: "not P"

#### Implies ($\to$) - Conditional

True unless a true statement implies a false one.

Let P and Q propositions, then:

$$P \to Q$$
Read: "If P, then Q"

##### Truth table

| P   | Q   | $P \to Q$ |
| --- | --- | --------- |
| V   | V   | V         |
| V   | F   | F         |
| F   | V   | V         |
| F   | F   | V         |
|     |     |           |

<hr>

True if both statements are either true or false.

$$A \iff B$$
