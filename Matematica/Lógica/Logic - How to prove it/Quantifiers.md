## Definition

In logic, **quantifiers** specify the scope of a statement over a set of elements. The two main types are: Universal quantifier($\forall$) and Existential quantifier($\exists$).

#### Universal quantifier ($\forall$) 

Universal quantifier( $\forall$ ) - expresses that a property or statement is true for **all elements** of a set.

Example: $\forall x \in \mathbb{R},  x² \ge 0$
Meaning: "For all real numbers x, x² is non-negative"

#### Existential quantifier( $\exists$)

Existential quantifier( $\exists$) - expresses that a property or statement is true for **at least one element** of a set.

Example: $\exists x \in \mathbb{R}, x² = 4$
Meaning: "There exists a real number x such that $x² = 4$"
