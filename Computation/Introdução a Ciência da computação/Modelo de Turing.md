#computation #computer-science 
Em 1937, foi publicado o paper "On Computable Numbers with an Application to the Entscheidungsproblem (1936)", escrito por Alan Mattison Turing. 

Ps: Turing definiu matematicamente, contudo ele estava mais interessado na definição filosófica de computação. 

Antes de discutir as máquinas de Turing, vamos definir um computador como um processador de dados.

$$\text{dados de entrada(input)} \implies \text{computador} \implies \text{dados de saída(output)}$$
Uma máquina de propósito único.

Aqui o computador age como uma função definida que recebe os dados , processa-os, e por fim, retorna-os como dados de saída ,isto é, já processados.

**Problema:** Esse modelo pode representar um computador com propósito específico (ou processador). No entanto, computadores, do modo como o termo é utilizado, são máquinas de **propósito geral** -- ou seja, podem desempenhar uma séries de tarefas específicas.

### Entendendo o Modelo de Turing

O modelo de **Turing** é melhor para um **computador de propósito geral**, porque acrescenta um elemento extra de computação específica: o **programa**.

**Programa:** É um conjunto de instruções que diz ao computador o que fazer com os dados(ou seja, um **algoritmo**).
