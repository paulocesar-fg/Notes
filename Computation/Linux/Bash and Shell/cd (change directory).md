## Traversing directory

You use the *change directory* command (cd) to move your shell session to another directory in the Linux filesystem.

Sintax

```bash 
	cd [destination]
```

Ps: An **absolute directory** reference always begins with a forward slash(/), indicating the virtual directory system's root.

Ps: **A relative path** is one which starts with the name of a directory connected to the current directory.
