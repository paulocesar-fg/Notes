## Which Command

The `which` command in Linux is used to **find the path of an executable** that is in the system's `PATH`.

### Basic Syntax
```bash
which [command]
```

## Type Command

The `type` command in Linux is used to **display detailed information about a command**, such as whether it is a builtin, alias, or executable.

### Basic Syntax
```bash
type [command]
```
