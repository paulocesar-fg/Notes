## Definition 

the `wc`(word count) command in Linux displays three numbers followed by filename. From left to right, these numbers represent:

##### Syntax:
```bash
wc [options] [file]
```

1 - The number of lines.
2- The number of words(the Linux word count)
3- The number of bytes.

### Getting specif counts

`-l` shows only the line count;
`-w`shows only the word count;
`-c` shows only the byte count;
