The `mkdir` command create a directory in Linux right from terminal or command prompt.

* creating a single directory
```bash
mkdir directory
```

* Creating multiples directories:
```bash
mkdir dir1 dir2 ... dirN 
```
#### Creating Nested Directories

Use the -p (parent) flag to create a directory and its parent directories simultaneously.

Example:

```bash
mkdir -p books/math/favorites
```
