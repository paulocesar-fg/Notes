## Notes

### Function

The  `git status` command display the status of the working directory and staging area. 

### Options

-s / --short Short, compact output.
-b / --branch Show branch information( with short format `git status -sb`)
--porcelain  Machine-readable output(used in scripts)
--long - Default Behavior. 
--u / --untracked-files 
--ignored  Useful to debug .gitignore
